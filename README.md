# Página da lembrancinha — NPK 20-00-20

Site estático feito com HTML e CSS, pronto para publicar no GitHub Pages.

## Arquivos
- `index.html`: conteúdo da página.
- `style.css`: identidade visual e layout responsivo.

## Publicar pelo GitHub

1. Crie um repositório público no GitHub, por exemplo `lembrancinha-npk`.
2. Envie `index.html` e `style.css` para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois salve.
6. Aguarde a publicação. O endereço será parecido com:
   `https://SEU-USUARIO.github.io/lembrancinha-npk/`

## Antes de imprimir
- Substitua o círculo "LOGO do colégio" no topo pela logo oficial, se tiver autorização para utilizá-la.
- Abra o endereço publicado no celular e teste a leitura e a aparência.
- Só depois gere o QR Code usando o endereço definitivo do GitHub Pages.
